# Problems

Given a string `s`, determine the length of its longest substring that consists only of unique characters.

A substring is a contiguous sequence of characters within a string.

## Example

```text
Input: s = "abcba"
Output: 3
```

Explanation: `"abc"` is a longest substring containing only unique characters. `"cba"` is another valid answer of length `3`.

# Constraints

- `s` may be empty.

# Edge cases

- `s` is empty.
- `s` contains one character.
- Every character in `s` is unique.
- Every character in `s` is the same.
- A repeated character appears inside the current candidate substring.
